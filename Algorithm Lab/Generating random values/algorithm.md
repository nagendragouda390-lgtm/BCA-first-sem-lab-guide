# Algorithm: Generate a Random Number

1. Start.
2. Declare an integer variable `r`.
3. Initialize the random number generator using the current time.
4. Generate a random number using `rand()`.
5. Use `rand() % 10 + 1` to generate a number between 1 and 10.
6. Store the generated number in `r`.
7. Display the random value.
8. Wait for a key press.
9. Stop.
