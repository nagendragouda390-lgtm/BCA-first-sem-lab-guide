# Partitioning of an array

1. Start
2. Declare 3 array `a`, `b`, `c` and `mid`, `i`, `n`.
3. Read value for size as `n`.
5. Read `n` values for array `a`.
6. Calculate `mid = n/2`.
7. assign values upto `mid-1` of `a` to `b`.
8. and remaining elements to `c`.
9. Display `b` and `c` as partitioned array.
10. stop.
