# Algorithm for generating prime numbers 

1. Start
2. Declare variables `n`,`i`,`j`.
3. Read value for `n`.
4. Start for loop from `i = 2` until `i <= n`.
5. Contruct another for loop from `j = 2` until `j < n`.
6. Check `i % j == 0`.
7. If True Come out of second loop.
8. And then Check `i == j`.
9. If True display value of `i`.
10. Stop
