# Calculating value of cosine without using built-in function.
## Algorithm
1. Start
2. Create variable x, cos_x
3. Read value for x.
4. convert degree to radian
    `` x = x × π/180``
5. calculate cos value using tailor series

``. cos_x = 1 - x²/2! + x⁴/4! - x⁶/6!``

6. Display cos_x value.
7. Stop
