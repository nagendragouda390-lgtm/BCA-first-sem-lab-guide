# Algorithm for Numbers divisible by 7 from 100 to 200
1. Start
2. Declare variables ```i```.
3. intialize ```sum = 0``` and `count = 0`.
4. start loop from `i = 100`.
5. check whether `i <= 200`.
6. check if `i % 7 == 0`.
7. If True display value of `i` and add 1 to count and add `i` to `sum`.
8. Increase `i` by 1.
9. repeat step from 5 to 8 until `i` > 200.
10. Display value of `sum` and `count`.
11. Stop
