<h1>Algorithm for Factorial Computation<\h1>
1. Start
2. Declare variables `i`, `n`.
3. Initialise `fact = 0`.
4. read value for `n`.
5. If `n == 0` display 1.
6. Assign `i` value to 2.
7. Check `i <= n`.
8. If True multiply `fact` by `i` and restore it.
9. Increment `i` by 1.
10. Repeat steps 7 to 9 untill `i > n`.
11. Display value of `fact`.
12. Stop
